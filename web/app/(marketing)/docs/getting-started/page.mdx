# Getting started

Three steps take you from an empty account to a typed result   without spending a
credit or ringing a phone.

## 1. Add a few contacts

Open **Contacts → Import CSV**, or paste straight from a spreadsheet. Three rows is
enough to start.

Recognised columns are `name`, `phone`, and `note`. A header row is optional; without
one, columns are read in that order.

```text
name,phone,note
Aditi Sharma,+15555550100,asked about Bali in December
Rahul Verma,+15555550101,honeymoon package enquiry
Priya Nair,+15555550102,family trip to Singapore
```

Every row is validated up front. Numbers must be E.164   a leading `+` and a country
code   and a bare ten-digit number is assumed to be in your default region. A row
that fails is flagged inline with the reason, never silently dropped.

Those sample numbers are reserved fictional ones in the `+1 555 0100–0199` range and
cannot connect to a real person.

## 2. Pick a campaign

A campaign is two things: a goal written in plain English, and the fields you want
back from every call.

Start with a built-in template   marked `TEMPLATE`, duplicate one to edit it. Reading
a template's goal is also the fastest way to see what a good goal looks like: see
[Writing a good goal](/docs/writing-a-good-goal).

## 3. Read the result

Open any row. The conversation sits on the left; on the right, the extracted fields
and the triage decision as a short chain   `Frustration detected → Needs a person`.

That chain reads from typed fields, never from prose. The reason a call was
escalated is a value you can check, not a sentence somebody wrote.

## 4. Going live

Turn the dry-run switch off when you're ready. It's the only switch in the product
that asks for confirmation   showing the contact count, the credit estimate, the
calling window, and whether the allowlist is on.

> **Before that first live run**
>
> 1. Put your own number on the **allowlist**   while it holds anything, nothing
>    else can be dialled.
> 2. Set the **per-run ceiling** low, three or five, and raise it once a real call
>    has gone through cleanly.
>
> Both live in [Safety configuration](/docs/safety-configuration).
